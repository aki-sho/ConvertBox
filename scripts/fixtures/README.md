# Image test fixture

`rainbow.heic` is the 451 × 461 HEVC-encoded test pattern from
[libheif's test data](https://github.com/strukturag/libheif/blob/master/tests/data/rainbow-451x461.heic).
Its upstream filename is `rainbow-451x461.heic`. The upstream license is included
in `LIBHEIF-COPYING`. It is used only for offline image conversion tests and is
not included in the application package.
